💡 How to add images to questions & answers
Upload an image

Click the image icon to upload any image file from your device (max 2 MB). The image is embedded directly in the card.

Pick from Library

Click the grid icon to choose an image you already uploaded to the Image Library (Data page). Stored as a filename reference — not embedded.

Text + image (mixed)

Type text and pick an image in the same field. A position row appears below:

Above
Image above text
Inline
Side by side
Below
Image below text

In CSV/Excel, put the image tag and text on separate lines in the same cell:

What is this?
[LOCAL:dog.jpg]
✕ Remove an image

When an image is set, a ✕ Remove button appears beneath the preview. Click it to clear the image. Click the image or grid icon at any time to replace the current image.
